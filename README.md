# maxpatcher

Неофициальный PowerShell-скрипт, который делает **копию** десктопного мессенджера Max, где отключены:

- окна выбора файлов (вложения, аватар, обложка);
- окна «Сохранить как»;
- выбор папки загрузок в настройках;
- перетаскивание файлов в чат.

Правки вносятся только в ресурсы интерфейса (QML) внутри `max.exe` и `max-service.exe` копии. Программный код не меняется.

## Запуск

Для установленного Max:

```powershell
powershell -ExecutionPolicy Bypass -File Patch-MAX.ps1
```

Для папки с `max.exe` или для `MAX.msi`:

```powershell
powershell -ExecutionPolicy Bypass -File Patch-MAX.ps1 -Source <папка с max.exe или MAX.msi> -Dest <куда>
```

- Оригинал не трогается: скрипт работает только с копией. MSI он только распаковывает (`msiexec /a`), ничего не устанавливает.
- Без `-Dest` копия кладётся в `MAX_patched` рядом со скриптом.
- В конце скрипт печатает, какие из 8 правок применены.

Запускайте копию **только** через `Start_MAX_patched.cmd` внутри `MAX_patched` (скрипт создаёт его сам). Этот файл задаёт `QML_DISABLE_DISK_CACHE=1`. Без этой переменной Qt использует встроенный в exe уже скомпилированный интерфейс, и правки не действуют.

## Ограничения

- Это **не** запрещает процессу доступ к файлам на уровне системы. Убраны только пункты интерфейса. Для настоящей изоляции нужна песочница или отдельная учётная запись Windows.
- Цифровая подпись исправленных exe недействительна.
- Скрипт проверялся только на распаковке версии 26.41.1. Исправленная копия ни разу не запускалась в работе.
- На других версиях скрипт может не подойти. Тогда он сообщит «NOT FOUND» и оставит такие блоки без изменений.
- Max — продукт VK. Этот проект неофициальный и с VK не связан.
- Используйте на свой риск.
