# Как пользоваться maxpatcher: пошаговая инструкция

Эта инструкция для обычного пользователя Windows. Специальных знаний не нужно: достаточно уметь скачать архив и открыть окно PowerShell.

---

## 1. Что нужно и что получится

**Нужно:**

- Windows 10 или Windows 11.
- Max для Windows, версия **26.41.1**. Подойдёт любой из двух вариантов:
  - Max уже установлен на компьютер;
  - скачанный с max.ru установщик `MAX.msi` (устанавливать его не нужно).

**Что получится:**

- Рядом со скриптом появится отдельная папка `MAX_patched` с копией Max. Установленный Max и файл `MAX.msi` не изменяются.
- Копия запускается в изоляции Windows (AppContainer). Max в ней **не видит ваши папки**: Документы, Загрузки, Рабочий стол, Изображения, Видео, Музыку и остальное содержимое вашего профиля.
- Max хранит свои данные только в своих папках: `%LOCALAPPDATA%\ONEME`, `%APPDATA%\ONEME` и `%LOCALAPPDATA%\MAXIsolated`.

**Что НЕ получится, и это сделано намеренно:**

- прикреплять к сообщениям файлы и фото;
- сохранять файлы через «Сохранить как»;
- перетаскивать файлы в чат;
- выбирать папку для загрузок.

## 2. Скачать

Подойдёт любой способ:

- **ZIP-архив.** Откройте https://github.com/chvdbhcx-del/maxpatcher, нажмите зелёную кнопку **Code** и выберите **Download ZIP**.
  - Перед распаковкой щёлкните по архиву правой кнопкой → **Свойства**. Если внизу есть галочка **Разблокировать**, поставьте её и нажмите **ОК**. Иначе Windows может предупреждать о файлах из интернета.
  - Распакуйте архив.
- **git.** Выполните `git clone https://github.com/chvdbhcx-del/maxpatcher`.

Положите файлы в **простую папку**: без русских букв и без пробелов в пути, например `C:\maxpatcher`. Все шесть файлов должны лежать в одной папке:

```
Patch-MAX.ps1
Launch-MAX-Isolated.ps1
Start_MAX_isolated.cmd
Probe_MAX_isolated.cmd
Remove-MAX-Isolated.ps1
README.md
```

---

## 3. Закрыть обычный Max

Обычный Max должен быть закрыт полностью:

1. Закройте окно Max.
2. Найдите значок Max в трее, справа внизу возле часов. Если его не видно, нажмите стрелку «^».
3. Щёлкните по значку правой кнопкой и выберите **Выход**.

Если обычный Max продолжит работать, изолированная копия откажется запускаться и напишет об этом.

---

## 4. Сделать копию Max (Patch-MAX.ps1)

### Как открыть PowerShell в нужной папке

1. Откройте в Проводнике папку со скриптами, например `C:\maxpatcher`.
2. Щёлкните в адресной строке Проводника, сотрите текст, введите `powershell` и нажмите **Enter**. Откроется синее или чёрное окно, уже в этой папке.

### Команда

**Если Max установлен** на компьютер, скрипт найдёт его сам:

```powershell
powershell -ExecutionPolicy Bypass -File .\Patch-MAX.ps1
```

**Если у вас файл `MAX.msi`** или папка с `max.exe`, укажите путь к нему в параметре `-Source`:

```powershell
powershell -ExecutionPolicy Bypass -File .\Patch-MAX.ps1 -Source C:\Users\Имя\Downloads\MAX.msi
```

Здесь `C:\Users\Имя\Downloads` — пример: подставьте свой путь.

Если копию нужно положить не рядом со скриптом, а в другое место, добавьте `-Dest`:

```powershell
powershell -ExecutionPolicy Bypass -File .\Patch-MAX.ps1 -Source C:\Users\Имя\Downloads\MAX.msi -Dest C:\MAX_patched
```

Папка из `-Dest` должна не существовать или быть пустой. Без `-Dest` копия появится в папке `MAX_patched` рядом со скриптом.

**Что значит `-ExecutionPolicy Bypass`.** По умолчанию Windows не запускает скачанные скрипты PowerShell. Этот параметр разрешает запуск только этого скрипта и только в этот раз. Настройки Windows не меняются.

**Что делает скрипт:**

1. Находит Max. Если указан `MAX.msi`, распаковывает его во временную папку (`msiexec /a`, это не установка) и после работы удаляет её.
2. Копирует Max в `MAX_patched`. Установленный Max не изменяется.
3. Вносит в копию правки: 8 правок интерфейса и правку `tracernative.dll` (см. раздел «Как это работает» в README). Перед изменением `tracernative.dll` сохраняется её исходная версия `tracernative.dll.orig`.
4. Кладёт в копию файлы для запуска: `Start_MAX_isolated.cmd`, `Probe_MAX_isolated.cmd`, `Launch-MAX-Isolated.ps1` и `Remove-MAX-Isolated.ps1`.

### Как читать отчёт

В конце скрипт выводит список из 11 шагов. У каждого шага один из статусов:

| Статус | Что значит |
|---|---|
| `APPLIED` | правка применена |
| `ALREADY PATCHED` | правка уже была, скрипт запускали повторно |
| `NOT FOUND` | нужное место в файлах не найдено |
| `FAILED` | правку применить не удалось, файл оставлен без изменений |

Если в конце написано `11 of 11 steps in place`, всё готово. Код завершения скрипта в этом случае 0.

**Если есть `NOT FOUND` или `FAILED`:** скорее всего, у вас другая версия Max, не 26.41.1. Ничего не сломано: установленный Max не менялся, а копию в `MAX_patched` можно просто удалить. Пользоваться такой копией не стоит. Для другой версии скрипт нужно дорабатывать.

## 5. Запустить Max

1. Откройте папку `MAX_patched`.
2. Дважды щёлкните по файлу **`Start_MAX_isolated.cmd`**.
3. Откроется окно консоли с подробностями, а затем окно Max.
4. Окно консоли **не закрывается само**: внизу будет «Press any key» / «Нажмите любую клавишу». Это нормально, после запуска Max его можно закрыть.
5. В первый раз войдите в аккаунт, как обычно: по номеру телефона и коду.

**Важно:** не запускайте `max.exe` напрямую двойным щелчком. Без `Start_MAX_isolated.cmd` изоляции нет, и Max видит все ваши папки.

---

## 6. Проверить изоляцию (Probe_MAX_isolated.cmd)

Дважды щёлкните по **`Probe_MAX_isolated.cmd`** в папке `MAX_patched`. Max при этом не запускается: внутри той же изоляции выполняются короткие проверки. Результат появится в окне и в файле `launch.log`.

Что должно получиться:

| Строка в отчёте | Ожидается | Что значит |
|---|---|---|
| `list app folder` | список файлов | Max может читать свою папку |
| `list user profile` | ошибка доступа | ваш профиль закрыт |
| `list Downloads` | ошибка доступа | «Загрузки» закрыты |
| `list ONEME data` | без ошибки | у Max есть доступ к своим данным |
| `list C:\Windows\Fonts` | число файлов | шрифты доступны |
| `write to data Temp` | `probe` | Max может писать в свою временную папку |
| `write to app folder` | ошибка доступа | программу нельзя изменить изнутри |
| `write to ONEME` | без ошибки | Max может сохранять свои данные |
| `registry HKLM MachineGuid` | значение | системный реестр читается |
| `registry HKCU write` | ошибка доступа | ваш раздел реестра на запись закрыт |
| `named pipe \\.\pipe\crashpad_*` | `PIPE FAILED` | так и должно быть: из-за этого нужна правка `tracernative.dll` |
| `named pipe \\.\pipe\LOCAL\*` | `PIPE OK` | с правкой сборщик сбоев Max работает |
| `loopback 127.0.0.1` | `LOOPBACK OK` | связь между частями Max внутри компьютера работает |
| `internet https://max.ru` | ответ `HTTP/...` | интернет доступен |

Строка `registry HKCU\Software\max (read)` может показывать ошибку: это не страшно.

## 7. Если что-то не так

**Max не открывается, или окно Max сразу закрылось.**
Посмотрите окно консоли: в нём написана причина. Частые случаи:

- `Max is already running`: обычный Max не закрыт. Закройте его через значок в трее (шаг 3) и запустите снова.
- `max.exe EXITED within 5 s`: Max запустился и сразу закрылся. Проверьте, что в начале отчёта есть строки `tracernative check: ... PATCHED`. Если там `NOT PATCHED`, запустите `Patch-MAX.ps1` заново.

**Windows SmartScreen или Защитник Windows предупреждает о скриптах или файлах.**
Это ожидаемо. Скрипты скачаны из интернета, а у исправленных файлов Max (`max.exe`, `max-service.exe`, обе `tracernative.dll`) цифровая подпись больше недействительна. Запускайте только файлы из этого репозитория, скачанные с GitHub. Если не уверены, не запускайте.

**Где лог.** Файл `launch.log` лежит в папке `MAX_patched` рядом с `Start_MAX_isolated.cmd`. Он перезаписывается при каждом запуске.

**Перед тем как кому-то отправить лог**, откройте его в Блокноте и посмотрите. В конец лога попадают последние строки логов самого Max: там может быть служебная информация вашего аккаунта. Удалите всё, что не хотите показывать: номер телефона, имена, идентификаторы.

**Куда писать.** Создайте issue в репозитории: https://github.com/chvdbhcx-del/maxpatcher/issues. Опишите, что делали, и приложите очищенный от личных данных фрагмент `launch.log`.

## 8. Откат: как всё убрать

1. Закройте изолированный Max.
2. Откройте PowerShell в папке `MAX_patched` (как в шаге 4) и выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Remove-MAX-Isolated.ps1
   ```

   Скрипт снимает права изоляции с папок и удаляет профиль изоляции Windows `MAX.Isolated`.

   С параметром `-DeleteData` он дополнительно удаляет папку `%LOCALAPPDATA%\MAXIsolated`:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Remove-MAX-Isolated.ps1 -DeleteData
   ```

   Данные Max в `%LOCALAPPDATA%\ONEME` и `%APPDATA%\ONEME` не удаляются: их использует и обычный Max.
3. Удалите папку `MAX_patched`.
4. Пользуйтесь установленным Max как обычно: он не изменялся.

Вручную `tracernative.dll` можно вернуть так: удалите исправленный файл и переименуйте `tracernative.dll.orig` обратно в `tracernative.dll`. Файлов два: в `MAX_patched` и в `MAX_patched\max-service`.

## 9. Что работает

| Возможность | Состояние |
|---|---|
| Запуск Max в изоляции | работает (проверено на одном компьютере, Max 26.41.1) |
| Вход в аккаунт | не проверено подробно |
| Переписка | не проверено подробно |
| Звонки | не проверено |
| Микрофон | не проверено |
| Камера | не проверено |
| Уведомления Windows | не проверено |
| Встроенные веб-окна и мини-приложения (WebView) | не проверено |
| Прикрепление файлов и фото | не работает (отключено намеренно) |
| Перетаскивание файлов в чат | не работает (отключено намеренно) |
| «Сохранить как», выбор папки загрузок | не работает (отключено намеренно) |
| Скачивание файлов в «Загрузки» | не работает: папка закрыта изоляцией |
| `Remove-MAX-Isolated.ps1` (откат) | не проверено |

## 10. Предупреждения

- Проект **неофициальный**. Max — продукт VK, этот проект с VK не связан.
- Вы используете его **на свой риск**.
- Сервис может посчитать изменённое приложение нарушением правил. Нельзя исключать **блокировку аккаунта** со стороны сервиса.
- После обновления Max правки перестают действовать, а для новой версии скрипт может не подойти (`NOT FOUND`). Автообновление в копии не используйте.
- Цифровая подпись исправленных файлов недействительна. Windows и антивирус могут относиться к ним настороженно.
- Изоляция закрывает Max доступ к вашим папкам, но это не антивирус и не защита от всего на свете.
